# 常见问题

## 为什么画质只有 480P？

**先扫码登录。** 未登录时 只返回 480P，这是 下载接口的限制，与软件设置无关。

已经登录了还是糊？看右上角状态栏是不是显示 `有效期已过` / `登录已过期` —— 登录态会过期，按提示重新扫码即可。

## 二维码扫不上 / 一直刷不出来

二维码由 B站接口实时生成，**需要联网**。网络不通时界面会停在旧图或空白，点 **取消** 重开一次即可。

## 加载歌单后显示「共 0 首」

按顺序排查：

1. 文件是不是真的 `.xlsx`（`.xls` / `.csv` 不支持）；
2. 内容是否写在**第一个工作表**；
3. 曲名是否在 **A 列**、从**第 2 行**开始；
4. 时间列的分隔符是不是**半角** `-`。

详见 [歌单格式](/guide/songlist)。

## 某首歌下载失败 / 日志写「跳过: 无BV号」

- `跳过: 无BV号` → 该行 B 列为空，补上 BV 号；
- 其它下载失败 → 软件会**自动重试一次**；仍失败通常是**视频已删除 / 需要会员 / 网络波动**，日志里会给出具体原因。

## MP3 属性页的「备注」为什么是空的？

这是**已知限制**，不是没写入：

ffmpeg 的 ID3v2 写入器只接受「4 字符且以 `T` 开头」的标签名，标准注释帧 `COMM` 会被它挡掉；而 Windows 属性页的「备注」恰好只认标准注释帧。

影响范围：

- **MP4 不受影响** —— 属性页「备注」能看到完整溯源信息；
- **MP3** 用[验真工具](/reference/verify)和 ffmpeg 都**能正常读回**，只是 Windows 属性页看不到。

## 启动后有 1~5 秒是纯色，之后背景才出来

正常。主界面背景是**在线随机动图**，每次启动都实时抓一张新的（不落磁盘缓存），下载 + 抽帧需要几秒。抓到之前就是纯色画布。

抓不到（断网）时保持纯色，**不影响任何功能**。运行中每 20 分钟还会自动换一张。

## 生成很慢

耗时几乎全在**下载**（每首歌一个视频）与**转码**上：

- 登录后能拿 1080P 源，源越大下载越久；
- 勾选「增量生成」可跳过已剪好的片段；
- MP4 明显比 MP3 慢（要重编码画面），再勾歌词烧录又慢一档。

## 提示「登录已过期」

生成前软件会向 确认一次登录态。过期时给你两个选择：

- 选 **是** → 立即扫码重新登录，成功后**自动继续**本次生成（能拿 1080P）；
- 选 **否** → 明知只有 480P 也照常生成。

## 点「检查更新」失败

检查更新需要联网访问发布源。网络不通或发布源暂时不可用时会提示失败，**不影响**软件其它功能。

## 找不到 output 文件夹

在**程序 exe 所在目录**下的 `output\`。点界面上的 **打开输出目录** 可直接打开（还没有产出时会打开程序目录）。

## 软件为什么有 112 MB？

大头是**内嵌的 .NET 8 自包含运行时**（约 160 MB，压缩后约占 100 MB）

换来的是**双击即用、用户不需要自己装 .NET**。

## 能完全离线用吗？

不能。素材要 下载、歌词要在线搜索。
