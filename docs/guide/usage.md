# 使用教程

主界面从结构上分四块：**导航栏**（左侧标题+版本号、右侧 B站登录与状态）、**设置区**（一张「模式选择」卡片）、**歌单列表**、**底部操作栏**（按钮 + 进度条 + 运行日志）。

## 模式选择

![模式选择卡片](/screenshots/settings.png)

卡片分三行：**模式**（三颗胶囊）、**音量**、**歌词 / 增量生成**。

### 模式决定输出格式

三颗胶囊**必须选一个**（默认选中 **音频倒计时**）—— 输出格式直接由它推导，界面不再单独选格式：

| 模式 | 输出成品 | 曲间插什么 |
| --- | --- | --- |
| **音频倒计时** | `随舞音频_*.mp3` | 内置倒计时音效 `assets\音频倒计时.mp3` |
| **视频倒计时** | `随舞视频_*.mp4` | 内置倒计时视频 `assets\视频倒计时.mp4`（音、画都有） |
| **聚焦预告** | `随舞视频_*.mp4` | 用**下一首自己**的画面做预告：虚化铺底 + 中央实景窗（白描边）+ 底部《歌名》 |

一个都不选就点 **开始生成** 会被拦下并提示 —— 没有模式就没有输出格式。

::: tip 既想要 MP3 又想要 MP4？
跑两次生成、各选一次模式即可。第二次片段会命中缓存，很快。
:::

::: tip 怎么换模式 / 怎么取消
想换成别的模式，直接点另一颗胶囊即可。已选中的胶囊再点一次会**取消选中** —— 但三颗全灭时无法生成，所以这更像是一个「手滑点掉」的中间态。
:::

### 音量均衡

勾选后把每首的统一到 **-14 LUFS**（主流音乐平台常用的响度标准）。

**强烈建议勾选** —— 不同 B站素材的原始音量差异很大，不均衡就会出现「这首震耳、下一首听不清」。

### 音量（dB）

在均衡之后再整体增减，范围 **-12 ~ +12 dB**，默认 `3`。觉得整体偏小就上调。

### 歌词

| 模式 | 说明 |
| --- | --- |
| 无歌词 | 不处理歌词 |
| 在线歌词库 | 按**曲名**在线搜索歌词（网易云 → LRCLIB → LrcAPI，免费、无需登录，中日英文均可）。**视频模式烧录进画面**；**音频倒计时模式写成同名 `.lrc` 文件** |

::: tip 音频模式的歌词是同名 .lrc 文件
MP3 没有画面可烧，所以会额外在 `output\` 里生成一个与音频**同名**的 `.lrc`：

```text
output\随舞音频_20260916_111905.mp3
output\随舞音频_20260916_111905.lrc
```

用支持同名歌词的播放器打开 mp3（PotPlayer、foobar2000、多数手机播放器），歌词会自动滚动。时间轴按**成品**算（已计入裁剪起点与前面几首的间隔），与声音是对齐的。
:::

### 增量生成（复用片段）

勾选后，**已经剪好的片段会被复用**，不再重复下载与剪辑 —— 适合「只改了歌单一两首，想快速重出一版」。

不勾选则每次全量重来（默认）。

## 曲间间隔

每首歌**前面**会插入一段间隔。**界面上没有秒数设置** —— 间隔多长由素材本身决定：

| 模式 | 间隔时长 |
| --- | --- |
| 音频倒计时 | 内置素材 ≈ **5.5 秒** |
| 视频倒计时 | 内置素材 ≈ **4.8 秒** |
| 聚焦预告 | 预告片本身长度（取倒计时素材长度与源可用时长中较短的那个） |

::: tip 想调长一点 / 短一点？
**直接替换 `assets\` 里的素材文件**即可，不用改任何设置、也不用重开软件。
:::

::: warning 聚焦预告找不到画面时会退成静音黑屏
聚焦预告要用**下一首的画面**。如果素材只有纯音频、或裁剪起点已超出素材长度，那一段会退化为**静音 + 黑屏**（日志会写 `聚焦预告: 无可用视频源，使用空白间隔`），不影响后面的拼接。
:::

::: tip 想换成自己喜欢的倒计时音 / 视频？直接替换文件即可
`assets\` 目录下的倒计时素材**可以随意替换成你自己的文件**，只要**文件名保持和原来一模一样**——

| 想换 | 怎么做 |
| --- | --- |
| 倒计时音频 | 用你的 mp3 覆盖 `assets\音频倒计时.mp3` |
| 倒计时视频 | 用你的 mp4 覆盖 `assets\视频倒计时.mp4` |

软件**按文件名加载**，换文件不用改任何设置、也不用重开软件。
:::

## 歌单操作

![歌单列表操作区](/screenshots/songlist-zoom.png)

| 操作 | 说明 |
| --- | --- |
| **重新加载** | 重新读取当前歌单文件（改完 xlsx 不用重开软件） |
| **随机打乱** | 把歌曲顺序随机重排 |
| **拖动行** | 直接拖动表格行调整顺序（顺序 = 成品播放顺序） |
| **复制选中行** | 右键 → 复制，或按 `Ctrl + C`；制表符分隔，可直接粘回 Excel |

## 开始生成

点 **开始生成** 后按钮区变为「停止」，进度条按歌曲数推进。日志里能看到完整四阶段：

1. **第一阶段：下载素材** —— 逐首从 B站下载（命中缓存的直接跳过）；
2. **第二阶段：重试失败** —— 对下载失败的自动重试一次；
3. **第三阶段：剪辑素材** —— 按时间裁剪、处理歌词、生成曲间间隔；
4. **第四阶段：拼接输出** —— 校验片段 → 拼接 → 写入溯源元数据。

过程中随时可点 **停止** 取消。

### 生成顺序

日志会打印一份成品时间轴，标明每首歌在成品里的起止位置：

```text
=== 生成顺序 ===
  00:00:05 - 00:01:10  极乐净土
  00:01:20 - 00:02:25  恋爱循环
```

### 完成之后

- 弹窗提示「音频/视频生成完毕!」；
- 成品落在 `output\`，文件名带时间戳（音频模式勾了歌词还会多一个同名 `.lrc`）；
- 日志给出**成品时长校验**（如 `MP3 时长校验: 812.34s`），与计算值偏差超过阈值会标出来。

## 清理缓存

`output\.temp\` 里保存着下载的原片、剪辑片段、倒计时拼接件。点 **清理缓存** 可整目录删除。

::: tip 什么时候先别清
勾了「增量生成」时，缓存里的片段正是要被复用的对象 —— 清了就等于要重新下载剪辑一遍。
:::

## 溯源与验真

成品**溯源信息写在**文件元数据**里：开发人 / 工具 / 序列号 / 生成时间。

查看方式与配套验真工具见 [溯源验真](/reference/verify)。
