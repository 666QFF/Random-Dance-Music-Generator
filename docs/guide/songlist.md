# 歌单格式

歌单是一个 Excel 文件（`.xlsx`）。软件读取**第一个工作表**，从**第 2 行**开始逐行往下读，三列依次是：

| 列 | 内容 | 是否必填 |
| --- | --- | --- |
| A | 曲名 | 必填（A 列为空的行会被跳过） |
| B | BV号 或 视频链接 | 必填（留空则该首被跳过） |
| C | 剪辑时间 | 可留空（= 整首） |

**第 1 行是表头，软件直接跳过**，写什么都行。

## A 列：曲名

任意文本。它同时会被用于**在线歌词搜索**，所以尽量写准确的歌名（如 `极乐净土`、`恋爱循环`）。

## B 列：BV号

支持三种写法，软件自动提取 BV 号：

| 写法 | 示例 |
| --- | --- |
| 纯 BV 号 | `BV1xx411c7mD` |
| 完整视频链接 | `https://www.bilibili.com/video/BV1yx411H7Yk` |
| 短链 | `https://b23.tv/xxxxxx`（下载时解析跳转） |

::: tip BV 号从哪来
打开 B站视频页，地址栏里 `video/` 后面那串 `BVxxxxxxxxxx` 就是。
:::

## C 列：剪辑时间

三种写法：

| 写法 | 含义 | 示例 |
| --- | --- | --- |
| `mm:ss-mm:ss` | 从 A 时刻截到 B 时刻 | `0:45-1:50`（第 45 秒到第 1 分 50 秒） |
| `mm:ss` | 从该时刻截到**片尾** | `2:10` |
| 留空 / 写 `全曲` | 整首都不裁 | |

::: tip 界面上显示的是「秒」
歌单里写 `0:45-1:50`，加载进软件后表格的「剪辑时间」列会换算成秒，显示为 `45s-110s` —— 两者是同一个区间，属正常现象。
:::

::: warning 两种自动修正
- 起点超过素材时长 → 自动改为从 **0 秒**开始；
- 终点超过素材时长 → 自动截到**片尾**。

两种情况都会在日志里打 `⚠ ... 已修正`，**不会中断生成**。
:::

## 常见歌单问题

| 现象 | 排查方向 |
| --- | --- |
| 加载后显示「共 0 首」 | 文件不是 `.xlsx`；或内容不在第一个工作表；或 A 列（曲名）整列为空 |
| 某首被跳过，日志显示 `跳过: 无BV号` | 该行的 B 列为空 |
| 时间填了但没生效 | 分隔符必须是**半角**连字符 `-`。`0:45~1:50`、`0:45 至 1:50` 都识别不了 |
| 表格里某首显示「全曲」但 C 列写了时间 | 只写在起点（如 `2:10`）时，含义是「从该点到片尾」 |

> 想让歌单里的顺序直接成为成品顺序，记住一句话：**表格里的行顺序 = 成品里的播放顺序**，改完用「重新加载」刷新即可。
