# 快速开始

**随舞音频生成器（RandomDanceGen）** 是一款 Windows 桌面工具：把一场随机舞蹈要用的歌，从 自动下载、按你指定的时间段裁剪、再按顺序拼接成**一个** MP3 或 MP4 —— 直接就能拿去放。

整个流程只有四步：

::: tip 四步产出成品
**① 登录（只使用随机音乐可以不登录）** → **② 准备歌单** → **③ 加载歌单** → **④ 开始生成**
:::

![随舞音频生成器主界面](/screenshots/main.jpg)

## 一、运行环境

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11（64 位） |
| 运行时 | **无需安装** —— 发布版已内嵌 .NET 8 运行时，双击即用 |
| 磁盘 | 约 200 MB（程序约 112 MB + ffmpeg 释放约 100 MB） |
| 网络 | 需要联网：下载素材、搜索歌词、检查更新 |

### 下载与首次运行

下载**混淆版**：💾 [RandomDanceGen.zip](https://github.com/666QFF/Random-Dance-Music-Generator/releases)

解压后双击 `随机舞蹈音频视频生成器.exe` 即可（自包含，无需安装 .NET）。

首次启动时软件会在后台做两件事，**界面可能先显示为纯色，属正常现象**：

1. **释放内置 ffmpeg** —— 发布版把 ffmpeg 压缩嵌在 exe 里，首次运行启动稍慢；
2. **联网抓取随机背景动图** —— 主界面背景是随机 ACG 动图，**每次启动都抓一张新的**（约 1~5 秒）。不等它也完全不影响使用。

## 二、登录（建议，为了高清）

不登录也能用，但 **只会返回 480P**；扫码登录后可拿到 **1080P** 源，成品清晰度差别很明显。

点击右上角 **登录**，用 **B站手机 APP** 扫码：

![扫码登录](/screenshots/bili-login.png)

登录成功后按钮变为「已登录」，右侧状态栏显示有效期，例如 `● 已登录 · 有效期至 2026-10-01`。

::: warning 登录态会过期
扫码登录的有效期通常为数月，也可能被其它设备顶下线。失效后软件会在**生成前**主动提示你重新登录 —— 如果不重新登录，B站**不会报错**，但会静默降为 480P。
:::

## 三、准备歌单

歌单是一个 **Excel（`.xlsx`）** 文件，只需要三列：

| 曲名 | BV号 | 剪辑时间 |
| --- | --- | --- |
| 极乐净土 | BV1xx411c7mD | 0:45-1:50 |
| 恋爱循环 | https://www.bilibili.com/video/BV1yx411H7Yk | 1:00-2:05 |
| 桃源恋歌 | BV1BW411E7Kd | 2:10 |

**建议直接下载模板改**：<a href="../songlist-template.xlsx" download>随舞歌单模板.xlsx</a>

> 三列的具体写法、BV 号支持哪些格式、时间怎么写，见 [歌单格式](/guide/songlist)。

## 四、加载歌单

点歌单区域的 **浏览** 选择做好的 xlsx，软件会立刻读入并在表格里逐首列出：

![加载歌单后的界面](/screenshots/songlist-zoom.png)

- 表格显示 **曲名 / 剪辑时间 / BV号** 三列；
- 日志提示 `已加载 N 首歌曲`；
- 表格顺序就是生成顺序 —— 可先 **随机打乱**，或直接**拖动行**调整。

## 五、第一次生成

要产出一个能用的成品，最简操作：

1. **模式选择**：默认已点亮 **音频倒计时**（输出 MP3）；想要有画面的视频，就改选 **视频倒计时** 或 **聚焦预告**（输出 MP4）—— 输出格式由模式决定；
2. 勾选 `音量均衡`、音量 `3 dB`、歌词 `无歌词`（音频模式想要滚动歌词就选「在线歌词库」，会额外生成同名 `.lrc`）；
3. 点 **开始生成**。

生成会在日志里分四个阶段推进：**下载素材 → 重试失败 → 剪辑素材 → 拼接输出**，完成后弹窗提示。

成品落在程序目录的 `output\` 里，文件名带时间戳：

```text
output\随舞音频_20260916_111905.mp3
output\随舞视频_20260916_111905.mp4
```

点 **打开输出目录** 即可直达。

## 目录与文件一览

| 路径 | 用途 |
| --- | --- |
| `output\` | 成品 `随舞音频_*.mp3` / `随舞视频_*.mp4`（音频模式勾了歌词还会附一个同名 `.lrc`） |
| `output\.temp\` | 下载的原片与中间片段（可删，见「清理缓存」） |
| `assets\` | 内置倒计时素材（`音频倒计时.mp3` / `视频倒计时.mp4`） |
| `%LOCALAPPDATA%\RandomDanceGen\tools\` | 内置 ffmpeg 的释放位置 |
| `%LOCALAPPDATA%\RandomDanceGen\` | 登录凭据等用户数据 |
